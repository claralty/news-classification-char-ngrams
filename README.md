# news-classification-char-ngrams
# Классификация новостей с помощью символьных n-грамм

Учебный NLP-проект, выполненный в рамках курса на факультете биоинженерии и биоинформатики МГУ. Цель работы — классифицировать новости по четырём тематикам и сравнить несколько вариантов TF-IDF-представления на основе символьных n-грамм.

## Задача и данные

Используется предобработанная версия [AG News Dataset](https://github.com/Xeanst/NLP_course_FBB/blob/main/data/news_preprocessed.csv), подготовленная для курса.

- 127 600 новостных текстов;
- четыре сбалансированных класса: World, Sport, Business и Science;
- обучающая выборка — 95 700 текстов, тестовая — 31 900;
- разделение 75/25 со стратификацией и `random_state=42`.

Исходный CSV-файл не хранится в репозитории: блокнот автоматически загружает его при первом запуске.

## Подход

1. Построен `Pipeline` из `TfidfVectorizer` и `MultinomialNB`.
2. Для векторизатора сравниваются анализаторы `char` и `char_wb`.
3. Для каждого анализатора проверяются четыре диапазона n-грамм: `(2, 4)`, `(3, 5)`, `(4, 6)` и `(3, 6)`.
4. Восемь конфигураций оцениваются с помощью `GridSearchCV` и пятикратной кросс-валидации по accuracy.
5. Лучший пайплайн оценивается на отложенной тестовой выборке, которая не участвует в подборе параметров.

## Результаты

| Показатель | Значение |
|---|---:|
| Лучший анализатор | `char` |
| Лучший диапазон n-грамм | `(4, 6)` |
| Средняя accuracy на кросс-валидации | 0,8961 |
| Accuracy на тестовой выборке | 0,8997 |
| Macro F1 на тестовой выборке | 0,8995 |

F1-score по классам: World — 0,9000, Sport — 0,9582, Business — 0,8678, Science — 0,8722.

![Сравнение конфигураций на кросс-валидации](images/cv_results.png)

Вывод об оптимальности параметров относится только к заданной сетке и фиксированному `min_df=5`. Небольшая разница между `char` и `char_wb` не позволяет без дополнительного статистического анализа говорить об устойчивом превосходстве одного анализатора.

## Как запустить

Требуется Python 3.10 или новее.

```bash
git clone https://github.com/claralty/news-classification-char-ngrams.git
cd news-classification-char-ngrams
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook news_classification_char_ngrams.ipynb
```

Для Windows команда активации виртуального окружения:

```bash
.venv\Scripts\activate
```

При первом запуске загружается CSV-файл размером около 50 МБ. Полный подбор параметров включает 40 обучений модели, поэтому выполнение соответствующей ячейки может занять заметное время.

## Что можно улучшить

- сравнить символьные и словесные n-граммы;
- добавить матрицу ошибок и разобрать пары классов, которые модель путает;
- проверить другие классификаторы, например логистическую регрессию или линейный SVM;
- расширить сетку параметров и отдельно исследовать влияние `min_df`.
